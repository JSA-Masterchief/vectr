    How search works

    Type a flight number the way you'd see it on a boarding pass (BA15, UA123) — Vectr resolves the airline's 2-letter code to the 3-letter code its transponder actually broadcasts (BAW15, UAL123) and matches it against live callsigns. You can also type the raw callsign directly. Not every flight is airborne right now — try a currently active one, or check a live flight board for one to test with.

    Vectr is free & open source. Flight data via The OpenSky Network. Map tiles via CARTO / OpenStreetMap. Not for operational or safety-critical use.
